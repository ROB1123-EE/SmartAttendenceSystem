# SmartAttendenceSystem
In this project , I am making an efficient system for attendence.
The Smart Attendance System is designed to automatically record attendance using a camera. Instead of calling names or signing sheets, the system recognizes faces and marks attendance instantly.
🎓 Schools & Universities – Teachers save time, and students can’t give proxy attendance.
🏢 Offices – Employees don’t need ID cards or fingerprint scans; attendance is marked automatically.
🎤 Events & Seminars – Organizers can track participants without manual check-ins.

⚙️ Working Procedure:
Register Faces → Each person’s face is saved in the system during setup.
Camera Captures Faces → When people enter the class/office, the camera detects their face.
Match & Verify → The system checks if the face matches a registered person.
Mark Attendance → If matched, attendance is recorded with date and time.
Generate Reports → Teachers or admins can view/download attendance records anytime.
✨ In short: Look at the camera → System recognizes you → Attendance done automatically!
